# Cloud-Vault
a full-stack cloud storage application  enabling secure authentication, folder management, drag-and-drop uploads, file previews.Integrated AWS S3 for scalable object storage and MongoDB Atlas for metadata management.


> Secure. Fast. Intelligent.

CloudVault is a modern full-stack cloud storage platform built with the MERN stack.

Unlike a traditional Google Drive clone, CloudVault focuses on secure file management, intelligent organization, modern UI, scalable cloud architecture, and production-ready engineering practices.
